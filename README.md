# OnlineMusicLibrary
Клиент-серверное приложение для управления музыкальной коллекцией с возможностью потокового воспроизведения аудио. Сервер хранит аудиофайлы и метаданные треков, клиент предоставляет графический интерфейс для просмотра, добавления, редактирования, удаления и воспроизведения музыки.

### Основные возможности
 - Просмотр списка треков с информацией (название, исполнитель, длительность)
 - Добавление новых треков с автоматическим определением длительности аудио
 - Редактирование и удаление существующих треков
 - Потоковое воспроизведение аудио с сервера
 - Отображение обложек треков (поддерживаются загруженные изображения и генерация по умолчанию)
 - Многопользовательский сервер, обрабатывающий запросы от нескольких клиентов
